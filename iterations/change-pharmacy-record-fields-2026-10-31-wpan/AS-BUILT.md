## Standing deviations

1. **The answer types are hand-written (F1).** The medicine, batch, supplier, order and sale/bill
   line answers' new fields are typed in the contracts until clinozy-be's response map carries them.
2. **The New sale price is a guide (F3).** It reads the first unexpired stocked batch; the server
   charges the batch it draws, which can differ when a batch runs out mid-sale.
3. **A return of a line sold before a `units_per_pack` change restocks in today's unit** (clinozy-be's
   Standing deviation; the change is refused while the medicine holds stock, D7).
