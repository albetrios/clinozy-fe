## Summary

- **Planned, not built:** — every ledger row is done.
- **Planned, not kept:** `BentoCard`'s `wide` prop (the rows place the cards); the brief's 560 / 900px
  breakpoints, the 2/3 + 1/3 Photos row and the coarse-pointer "Take photo" — traded for utilities the
  app already ships to keep Initial CSS within its budget (D18).
- **Built, not planned:** `usePhotoDrop` promoted to the file's shared hooks; `usePatientPhotosByIds`
  in `@/shared/hooks/usePatientPhotos/`.
- **Found on the way (not this change):** in the local stack the backend's hourly
  `subscription-seat-sync` reconcile suspends every member of the seeded demo clinic but one (no
  subscription → a ceiling of one seat), so the clinic's URLs 404 for the demo user until the
  memberships are reactivated; the same run logs "Worker process must not use unpinned database
  access". Reported to the user; nothing in clinozy-be is changed here.
- **Follow-ups for the next iteration:** none required. A Playwright E2E for select → compare can
  join the patient-file suite once clinozy-be's demo seed carries photos.
