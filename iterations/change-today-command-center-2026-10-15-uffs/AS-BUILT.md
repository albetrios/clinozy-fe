## Standing deviations

- **SD1 — the ranking inside a tier.** `BRIEF.md` change 1 says "within a tier the longest
  overdue first". The code ranks by minutes over each kind's own hot mark (`urgencyOf`,
  `today.attention.ts`), so a patient waiting in the clinic is not out-ranked by an old message.
- **SD2 — where a tile's badge sits.** `BRIEF.md` change 2 puts it "at its top end"; the code puts
  it on the count row, at its inline end, so a two-word lane name never wraps.
- **SD3 — the greeting row's shape.** The brief keeps one greeting row; the code stacks the
  greeting over the pulse and keeps the finder and the buttons on one line from `md`.
