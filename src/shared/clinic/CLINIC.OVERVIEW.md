# `src/shared/clinic/`

Cross-room clinic UI vocabulary for the launch's ten rooms (iteration
`launch-2026-09-30-jxmr`): the `clinic` i18n namespace's keys
(`clinic.constants.ts` — section names and descriptions, roles; more shared
statuses arrive with the rooms that need them). Room-only copy stays in each
room's own namespace (`today`, `leads`, … `users`).

Data contracts and fixtures live in `src/shared/api/clinic/`.
